# Carrom Pro — SFX

These clips are played by `AudioService`, gated by the Sound Effects setting:

| File | Plays on |
|---|---|
| `strike.ogg` | striker launch |
| `pocket.ogg` | a coin/striker drops into a pocket |
| `win.ogg` | match won |
| `lose.ogg` | match lost |

The game runs silently if any are missing.
